# Touch Base Consulting | Automated Agency OS

An automated, AI-powered client acquisition engine built for **Touch Base Consulting** based in Hermanus, South Africa. This system automates the entire sales cycle—from local SEO prospecting and CRM logging to dynamic micro-landing page generation, automated follow-ups, and closing proposals.

---

## 🚀 Tech Stack & Architecture

* **Engine:** Google Gemini API (`Gemini 3.1 Flash Lite`) via Google AI Studio.
* **Backend:** Vercel Serverless Functions (`/api/*`).
* **Frontend:** Static Command Center Dashboard (`/public/index.html`).
* **CRM Database:** Google Sheets via Google Apps Script Webhook.
* **Design Standards:** Strict adherence to agency branding (Deep Black `#0A0A0A`, Pure White `#FFFFFF`, and Harvest Gold `#B8860B`).
